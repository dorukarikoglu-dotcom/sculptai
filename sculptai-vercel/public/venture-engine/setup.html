ONE-TIME CONNECTION

Connect money in, traffic out.

The Venture Engine code is already deployed. These two external account connections are the remaining one-time steps.

1. Stripe Checkout

Checking…

  1. In Stripe Dashboard, create a restricted live API key for this Venture Engine. Give only the permissions needed to create/read Checkout Sessions and the Product/Price objects used by Checkout.
  2. In Vercel → project sculpt.ai → Settings → Environment Variables, add STRIPE_RESTRICTED_KEY for Production.
  3. Redeploy Production. This page will switch to Configured.

Never paste a Stripe secret/restricted key into ChatGPT, GitHub, client-side JavaScript, or a public file.

2. Google Ads allocator

The script reads our live allocation feed, creates/manages only campaigns prefixed VE_, and enforces 500 TL/day billed + 5,000 TL total billed hard caps. For safety it refuses to run in a non-TRY Google Ads account.

  1. Google Ads → Tools → Scripts → create a new script.
  2. Copy the prepared script below, paste it, authorize it, and run Preview once.
  3. If Preview has no safety/error message, schedule it Hourly.
